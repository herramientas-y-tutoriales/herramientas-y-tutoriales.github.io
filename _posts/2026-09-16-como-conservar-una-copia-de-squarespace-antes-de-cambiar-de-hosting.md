Antes de cambiar el hosting de un sitio Squarespace, guarda una copia estatica que puedas abrir, probar y entender fuera de la plataforma. No es solo un respaldo: es una forma de planear una migracion, revisar una renovacion o entregar un proyecto sin depender de una cuenta ajena.

![Lista de exportacion Squarespace](/assets/img/posts/2026-09-16-como-conservar-una-copia-de-squarespace-antes-de-cambiar-de-hosting/image-01-4a73f7039ad2.webp)

## Define para que sirve la copia

Empieza anotando si la copia sera un archivo, un sitio de prueba, una migracion o una nueva version publica. Para un respaldo basta con guardar los archivos. Para una version que sustituira al sitio necesitas revisar rutas, formularios, recursos y redirecciones.

[ExFlow para Squarespace](https://exflow.site/squarespace) puede recopilar un sitio publicado como HTML, CSS, JavaScript y archivos multimedia. Despues puedes descargar un ZIP o sincronizar la salida con Git, S3, FTP o un hosting estatico. El objetivo es conservar una version portable del sitio, no solo exportar contenido.

## Haz una lista corta de paginas importantes

Incluye la pagina principal, contacto, las paginas que reciben visitas, blog, recursos descargables y cualquier pagina usada en campanas. Añade tambien formularios, videos, enlaces externos y elementos protegidos por contraseña si son parte del proyecto autorizado.

Esa lista se convierte en tu prueba. Sin ella es facil mirar la portada, decir que todo funciona y descubrir semanas despues que un enlace importante apunta a un recurso perdido.

## Publica una version de prueba

No revises la copia solo desde una carpeta local. Sube los archivos a una URL de prueba para detectar rutas relativas, fuentes, scripts e imagenes que fallan cuando el navegador usa un host real. Abre las paginas importantes desde un telefono y un ordenador.

![Prueba responsive de sitio estatico](/assets/img/posts/2026-09-16-como-conservar-una-copia-de-squarespace-antes-de-cambiar-de-hosting/image-02-79626c3f40ee.webp)

Comprueba navegacion, imagenes, media cargada al hacer scroll, enlaces internos, titulos y descripciones. Luego prueba cada formulario. Una copia estatica puede conservar el aspecto de un formulario sin conservar el servicio que recibe los mensajes. Decide si se conectara a otra herramienta o si debe eliminarse de la copia.

## Deja la entrega preparada para la siguiente persona

Guarda el ZIP original y una nota con la fecha de exportacion, URL de prueba, destino de los archivos y resultados de la revision. Si el sitio seguira recibiendo cambios, Git ofrece un historial claro. Si solo necesita un archivo, una carpeta ordenada y un readme corto son suficientes.

![Entrega portable de sitio web](/assets/img/posts/2026-09-16-como-conservar-una-copia-de-squarespace-antes-de-cambiar-de-hosting/image-03-904929285aef.webp)

ExFlow tambien tiene exportadores para [Webflow](https://exflow.site/webflow) y [Framer](https://exflow.site/framer), pero en Squarespace el detalle clave suele ser asegurar que paginas, media, navegacion y formularios siguen teniendo una ruta clara despues de la exportacion.

Empieza con una copia de prueba antes de tocar el dominio. Cuando esa version pase tu lista de paginas y funciones importantes, tendras una base mucho mas tranquila para cambiar hosting o hacer una entrega.
